# Module 1 Summary

## What I Learned

Module 1 introduced me to the role of a Data Engineer and the importance of data engineering in modern businesses.

A Data Engineer is responsible for collecting data from different sources, combining it into a single, usable format, and preparing it so that other professionals, such as Data Scientists and Data Analysts, can use it to make informed decisions.

One of the main responsibilities of a Data Engineer is building and maintaining data pipelines. These pipelines automate the movement of data from its source to storage systems where it can be cleaned, transformed, analyzed, and reported on.

I also learned that Data Engineers manage the infrastructure that supports data collection, processing, and storage. This includes databases, data warehouses, cloud services, virtual machines, and networking components.

To become a successful Data Engineer, three categories of skills are important:

### Technical Skills
- SQL and databases
- Data warehouses
- ETL processes
- Data pipelines
- Big Data technologies
- Programming languages such as Python
- Cloud platforms
- Linux and operating systems

### Functional Skills
- Understanding business requirements
- Converting business needs into technical solutions
- Software Development Life Cycle (SDLC)
- Data quality
- Data security
- Privacy and governance

### Soft Skills
- Communication
- Teamwork
- Collaboration
- Problem-solving
- Critical thinking

## Key Takeaway

Data Engineers are responsible for making data available, reliable, and useful. They build the systems that collect, organize, and transport data so that businesses can use it to make better decisions.
